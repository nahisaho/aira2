# ADR-0001: Copilot-native specification development

## Context / 背景
Use musubix3 only for deterministic specification artifacts and evidence.

## Decision / 決定
Delegate planning, editing, research, reviews, security review, memory and subagents
to GitHub Copilot CLI. Do not introduce parallel agent runtimes.

## Consequences / 結果
Maintain explicit requirement/design/code/test IDs. Configure real verification
commands. Formal consistency is never proof of implementation correctness.
